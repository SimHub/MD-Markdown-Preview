Native Swift / AppKit · macOS 12+ · Zero Electron

Calm Markdown reading, manuscript diff & batch PDF.

A lightweight, 100% local Markdown & plain-text reader for macOS. No bundled browser, no server, no telemetry.

⬇ Download for macOS (.dmg) View on GitHub

Calm Reading & Live Reload

Read, Split, and Source views with table of contents, focus mode, GFM alerts, task lists, and instant reload on save.

Two-Document Manuscript Diff

Compare two full rendered documents side by side with word/sentence/paragraph badges — up to 40,000 text blocks.

Local Diff & Review Notes

Unified or side-by-side UTF-8 diff with per-hunk checkmarks and local review comments for exact file versions.

Search All Loaded Files

Find in the current document (⌘F) or search filenames and contents across all open files (⇧⌘F).

A4 PDF & Batch Export

Export a single file or reorder multiple open files into separate PDFs or one merged A4 document.

100% Private & Bilingual

Read-only, DOMPurify-sanitized, relative images scoped to each folder, and instant DE / EN UI switching.

First launch on macOS: This free open-source build is ad-hoc signed rather than notarized with a paid Apple Developer ID. Right-click MD Preview.app → Open on first launch, or run xattr -cr "/Applications/MD Preview.app".
